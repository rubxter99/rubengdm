# Dirección del portfolio

La web presenta a Rubén como desarrollador Full Stack con experiencia profesional y proyectos creativos. Su objetivo inicial es conseguir conversaciones con posibles clientes.

## Oferta inicial propuesta

1. Web de servicios para un negocio: páginas y secciones pactadas, versión móvil, contacto y publicación.
2. Mejoras de una web existente: diagnóstico, correcciones y evolución de funcionalidades con alcance definido.
3. Aplicaciones e integraciones: APIs, backend y conexiones con herramientas del cliente.

Presupuestar cada proyecto según alcance, contenidos, revisiones, integraciones, plazo y soporte. Ofrecer mantenimiento por separado con tareas y tiempos de respuesta definidos. No prometer disponibilidad ilimitada mientras se compagina con el empleo actual.

## Shopify

Preparar una tienda demo y una oferta concreta de configuración/personalización. No presentar experiencia Shopify como acreditada: no aparece en los CV. Con Shopify Partners, usar una tienda de transferencia a cliente para construir y entregar el proyecto; el cliente asume su plan, dominio y aplicaciones. Las tiendas de desarrollo destinadas a probar apps o temas son otra categoría y no se transfieren.

Fuente: https://help.shopify.com/en/partners/manage-clients-stores/client-transfer-stores

Dropshipping sería una línea de negocio distinta, con validación de producto, adquisición de clientes, proveedores y atención posventa. No hace falta montar una tienda propia para vender servicios de desarrollo web.

## Alojamiento

Cloudflare Pages permite empezar con un subdominio pages.dev y un plan gratuito. Netlify es otra opción y ya figura en los CV como rubxter.netlify.app; su plan Free admite proyectos comerciales, con límites de uso. Un dominio propio puede añadirse después sin contratar un VPS.

- https://developers.cloudflare.com/pages/get-started/direct-upload/
- https://developers.cloudflare.com/pages/platform/limits/
- https://www.netlify.com/blog/introducing-netlify-free-plan/
- https://www.netlify.com/pricing/

Para un dominio .com estándar, Porkbun muestra 11,08 USD de registro y renovación en la consulta del 6 de septiembre de 2026. Confirmar disponibilidad, impuestos, moneda y precio final antes de comprar. No es una reserva ni un precio garantizado.

https://porkbun.com/products/domains

Vercel Hobby está limitado a uso personal no comercial; no es la opción recomendada para una web orientada a captar clientes.

https://vercel.com/docs/plans/hobby
